Übersicht

Darum geht es

  • Eine Funktion bündelt zusammengehörigen Code unter einem Namen.
  • void heißt: die Funktion gibt keinen Wert zurück.
  • Definiert wird außerhalb von setup() und draw(), aufgerufen wird in draw().
  • Die Aufrufe in draw() laufen von oben nach unten.
  • Was mehrere Funktionen brauchen, muss global stehen.
