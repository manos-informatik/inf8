Übersicht

Darum geht es

  • Ein Boolescher Ausdruck ergibt true oder false.
  • Vergleiche prüfen Werte; &&, || und ! verknüpfen Bedingungen.
  • if führt einen Block aus, wenn seine Bedingung wahr ist.
  • else if prüft den nächsten Fall, else fängt den Rest auf.
