Die fünf Datentypen

int
Ganze Zahl, ohne Komma: 42, -7
float
Kommazahl, mit Punkt geschrieben: 3.14
boolean
Nur true oder false
char
Genau ein Zeichen in einfachen Anführungszeichen: 'A'
String
Zeichenkette in doppelten Anführungszeichen: "Hallo"

Achtung: '7' ist ein char, "42" ist ein String.

Was ist eine Variable?

Eine Variable ist ein benannter Speicherplatz mit einem Datentyp und einem Wert.

int x = 100;

Der Name x steht ab jetzt für den Wert 100. Änderst du den Wert, ändert sich jede Stelle mit, an der x benutzt wird.

Koordinaten ablesen

Der Nullpunkt liegt oben links, x geht nach rechts, y nach unten. Ein Rasterkästchen ist 10 Pixel breit.

rect(x, y, b, h) setzt die obere linke Ecke, circle(x, y, d) den Mittelpunkt.

Was macht draw()?

setup() läuft einmal, draw() danach immer wieder – hier Schritt für Schritt per Knopf.

Der Wert einer Variablen bleibt dabei erhalten: Was am Ende eines Zyklus drinsteht, gilt am Anfang des nächsten.

In Processing laufen die Zyklen von allein – frameRate(2) bremst sie auf zwei pro Sekunde, damit man zusehen kann.
