Die fünf Datentypen

      

        
int
Ganze Zahl, ohne Komma: 42, -7

        
float
Kommazahl, mit Punkt geschrieben: 3.14

        
boolean
Nur true oder false

        
char
Genau ein Zeichen in einfachen Anführungszeichen: 'A'

        
String
Zeichenkette in doppelten Anführungszeichen: "Hallo"

      

      
Achtung: '7' ist ein char, "42" ist ein String.

      

        
      

    

  


  

    

      
Was ist eine Variable?

      
Eine Variable ist ein benannter Speicherplatz mit einem Datentyp und einem Wert.

      
int x = 100;

      
Der Name x steht ab jetzt für den Wert 100. Änderst du den Wert, ändert sich jede Stelle mit, an der x benutzt wird.

      

        
      

    

  


  

    

      
Koordinaten ablesen

      
Der Nullpunkt liegt oben links, x geht nach rechts, y nach unten. Ein Rasterkästchen ist 10 Pixel breit.

      
rect(x, y, b, h) setzt die obere linke Ecke, circle(x, y, d) den Mittelpunkt.

      

        
      

    

  

  

    

      
Was macht draw()?

      
setup() läuft einmal, draw() danach immer wieder – hier Schritt für Schritt per Knopf.

      
Der Wert einer Variablen bleibt dabei erhalten: Was am Ende eines Zyklus drinsteht, gilt am Anfang des nächsten.

      
In Processing laufen die Zyklen von allein – frameRate(2) bremst sie auf zwei pro Sekunde, damit man zusehen kann.

      

        
      

    

  

  

    

      
Wie eine Zuweisung gelesen wird

      
Bei zaehler = zaehler + 2; wird zuerst die rechte Seite ausgerechnet, danach landet das Ergebnis links.

      
Was am Ende eines draw()-Zyklus drinsteht, gilt am Anfang des nächsten.

      

        
      

    

  


  

    

      
Wo gilt eine Variable?

      

        
global
vor setup() deklariert – im ganzen Programm nutzbar

        
lokal
in einem Block { } deklariert – nur dort nutzbar, und bei jedem Aufruf neu

      

      
Nicht jeder falsche Ort gibt eine Fehlermeldung. Manchmal läuft das Programm und rechnet trotzdem falsch.

      

        
      

    

  


  

    

      
Text und Wert zusammensetzen

      

        
+
hängt Text und Wert aneinander: "x = " + x

        
println()
schreibt und beginnt danach eine neue Zeile

        
print()
schreibt ohne Zeilenumbruch

      

      
Leerzeichen zählen mit. Sie gehören in den Text, nicht zwischen die Rechenzeichen.

      

        
      

    

  


  

    

      
width und height

      
Processing setzt width und height selbst auf die Werte aus size(). Wer damit rechnet, passt sich jeder Leinwandgröße an.

      
Feste Zahlen passen immer nur zu genau einer Größe.
